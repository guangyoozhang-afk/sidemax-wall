SIDE MAX 广告墙 - Android 5.1 TV

目标：
- Android 5.1 / API 22 及以上
- 横屏电视
- 全屏 WebView
- 自动打开 https://sidemax.cc/?page=wall
- 屏幕常亮
- JavaScript / DOM Storage 开启
- 网络加载失败 5 秒后自动重试
- 遥控器返回键不退出应用

构建环境：
- Android Gradle Plugin 3.5.4
- Gradle 5.4.1
- compileSdkVersion 28
- targetSdkVersion 28
- minSdkVersion 22

如果在线 APK Builder 要求导入 Android 项目：
将本目录作为 Android Studio/Gradle 项目导入。

如果在线 Builder 只接受 URL 而不能导入源码：
不要把此项目的代码粘到网页 URL 栏；应使用支持自定义 Android 项目/源码的构建方式。
